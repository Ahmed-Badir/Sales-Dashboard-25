# 📊 Sales Dashboard - 2025

An executive Power BI sales analytics dashboard providing comprehensive insights into financial performance, regional distribution, monthly trends, and customer segments for the year 2025.

---

## 🚀 Project Overview
This dashboard was designed and built to track, analyze, and visualize key performance indicators (KPIs) for sales operations. It enables stakeholders to quickly identify top-performing product segments, track regional profitability, and monitor monthly sales fluctuations.
